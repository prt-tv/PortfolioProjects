## Project: Layoffs Data Cleaning & Analysis

###  Overview
In this project, I worked with a global layoffs dataset and performed data cleaning and exploratory data analysis using SQL.

---

### 🛠 Skills Used
- SQL (MySQL)
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Window Functions (ROW_NUMBER, DENSE_RANK)
- Aggregate Functions (SUM, AVG, MAX)
- Common Table Expressions (CTEs)

---

### 📂 Files
- [`data_cleaning.sql`] [https://github.com/prt-tv/PortfolioProjects/blob/main/data_cleaning.sql] → Data cleaning process  
- `eda.sql` → Data analysis and insights  

---

###  What I Did
- Removed duplicate records  
- Standardized and cleaned data fields  
- Handled missing values  
- Converted date formats  
- Analyzed layoffs trends across companies, industries, and time  
- Identified key patterns using SQL queries  

---

### Key Insights
- Tech and Crypto industries experienced the highest layoffs  
- Layoffs peaked around 2022  
- A few companies contributed to a large portion of layoffs  
- Layoffs occurred in waves rather than a steady trend

This project demonstrates my ability to clean messy datasets and extract meaningful insights using SQL, helping understand real-world business trends.
